# SmartBudgetManager
A project for managing Budget 
README - SmartBudget Manager


About the Project
SmartBudget Manager is a simple Excel workbook designed to help users track monthly personal income and expenses easily.
File Structure
Dashboard: Visual summary, total calculations, and budget alerts.
Transactions: Data entry sheet for daily transactions.
Categories: Predefined expense categories and budget limits.
Quick Start Guide
Open SmartBudget_Manager.xlsx in Microsoft Excel.
Go to the Categories sheet to view or set monthly limits.
Go to the Transactions sheet to log daily income and spending.
Check the Dashboard sheet anytime to review your financial status.
